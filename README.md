# CollabBoard

> 🚧 Work in progress

**Live demo:** https://collabboard-qh8k.vercel.app

A full-stack project management app inspired by Linear/Jira. Built with Next.js, TypeScript, Prisma, and PostgreSQL

## Features

- Authentication (register/login) with hashed passwords and JWT sessions
- Project and task management with Kanban boards
- Real-time updates via WebSockets
- Role-based access (admin/member)
- Activity feed per project

## Tech Stack

- **Frontend:** Next.js 16, React, TypeScript, Tailwind CSS
- **Backend:** Next.js API routes
- **Database:** PostgreSQL + Prisma ORM
- **Auth:** NextAuth.js
- **Real-time:** Socket.io
- **Deployment:** Vercel + Railway
